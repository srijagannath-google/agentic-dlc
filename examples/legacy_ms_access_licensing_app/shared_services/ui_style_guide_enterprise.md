# Enterprise Digital Experience Style Guide

## Brand & Semantic Color Tokens
- **Primary Brand Navy:** `#002855`
- **Action Primary Blue:** `#1A73E8`
- **Success Green:** `#1E8E3E`
- **Warning Amber:** `#F9AB00`
- **Danger Red:** `#D93025`
- **Surface Background:** `#FFFFFF` / `#F8F9FA`

## Accessibility & Typography Mandate
- Compliance target: **WCAG 2.1 Level AA** (text contrast >= 4.5:1, UI component contrast >= 3:1, visible 3px focus ring `#1A73E8`).
- Every status indicator must include both a human-readable text label and an icon glyph.
